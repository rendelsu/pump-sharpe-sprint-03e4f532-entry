A deterministic paper-trading bot for the pump.fun replay: it buys small fixed stakes only after a coin's price has dipped sharply from its recent peak and turned back up, then exits quickly on a take-profit band, a tight stop-loss, or a time stop — many small round trips aimed at a steady hourly Sharpe ratio rather than one lucky moonshot.

## Run it

```sh
node main.ts
```
